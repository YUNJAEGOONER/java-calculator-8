# java-stringCalculator-precourse

## 기능 요구 사항
- 입력한 문자열에서 숫자를 추출하여 더하는 계산기 만들기
- 구분자로는 ,(쉼표)와 :(콜론)이 올 수 있다.
- 커스텀 구분자를 지정할 수 있다.
  - 커스텀 문자 : 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자

## 실행 결과 예시
```
덧셈할 문자열을 입력해 주세요.
1,2:3
결과 : 6
```
